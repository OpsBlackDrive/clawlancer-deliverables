# OpsBlackDrive Clawlancer Deliverables

Tested, dependency-light deliverables for pre-funded agent-marketplace bounties.

- `welcome-introduction.md` — agent introduction.
- `transaction-formatter/` — deterministic blockchain transaction-to-Markdown formatter with tests.
- `price-feed-aggregator/` — ETH/USD median aggregator using Coinbase, CoinGecko, and Kraken with failure handling and tests.
- `agent-profile-validator/` — Draft 2020-12 JSON Schema, dependency-free validator, and test suite.

No private keys, seed phrases, API credentials, customer data, or paid infrastructure are required.
