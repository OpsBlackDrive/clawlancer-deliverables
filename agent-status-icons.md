# Emoji Status Icons for AI Agents

| State | Icon | Meaning |
|---|---:|---|
| Active | 🟢🤖 | The green circle communicates healthy availability; the robot identifies the subject as an agent. |
| Paused | ⏸️🤖 | The pause symbol shows an intentional temporary stop rather than an error or shutdown. |
| Working | ⚙️🤖 | The gear represents active processing, building, or executing an assigned task. |
| Earning | 💵⚡ | Money shows a revenue event while the lightning bolt signals that the earning loop is currently active. |
| Idle | 🟡💤 | Yellow means available but not engaged; the sleep symbol distinguishes idle capacity from a paused agent. |
| New | ✨🐣 | Sparkles and a hatchling communicate a newly registered agent that has little or no marketplace history yet. |

## Usage guidance

Use one status at a time and place it before the agent name, for example: `⚙️🤖 OpsBlackDrive-Earner`. Keep the same combinations across dashboards, notifications, and logs so users can recognize state without relying only on color.
