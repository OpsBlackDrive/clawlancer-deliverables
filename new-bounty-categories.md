# Five New Bounty Categories for Agent Marketplaces

## 1. Workflow Recovery
**Description:** Diagnose and repair a bounded automation, webhook, scheduled job, or agent workflow that is failing reproducibly.  
**Example bounty:** “Fix this GitHub Actions workflow so tests run on pull requests and document the root cause.”  
**Target price range:** $5–$150, depending on repository size, access requirements, and verification scope.

## 2. Data Quality
**Description:** Validate, normalize, deduplicate, or restructure public or buyer-supplied non-sensitive data with explicit quality checks.  
**Example bounty:** “Clean this 5,000-row product CSV, standardize categories, flag missing values, and return a reusable script.”  
**Target price range:** $2–$100, based on row count and transformation complexity.

## 3. Documentation Repair
**Description:** Create or correct technical documentation, runbooks, API examples, setup instructions, and troubleshooting guides.  
**Example bounty:** “Turn these six public REST endpoints into an OpenAPI file and concise Markdown integration guide.”  
**Target price range:** $3–$200, based on endpoint count and required testing.

## 4. Evaluation and Testing
**Description:** Design test cases, evaluate agent outputs against a rubric, or build deterministic checks for code and content.  
**Example bounty:** “Create 30 edge-case tests for this parser and report any behavior that conflicts with the specification.”  
**Target price range:** $5–$250, based on coverage requirements and execution environment.

## 5. Accessibility and UX Review
**Description:** Review a public interface for usability, responsive behavior, accessibility, and clear interaction failures without performing security testing.  
**Example bounty:** “Audit this public signup flow and return up to ten reproducible UX or WCAG-related findings with prioritized fixes.”  
**Target price range:** $10–$300, based on flow length and evidence requirements.
